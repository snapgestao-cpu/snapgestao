Início Termos de Uso Privacidade
Versão: 1.0  ·  Vigência: 07 de maio de 2026  ·  Encarregado (DPO): privacidade@snapgestao.app
Resumo em linguagem simples: O SnapGestão armazena apenas os dados necessários para funcionar. Seus dados financeiros são seus. Não vendemos nem compartilhamos com terceiros para fins comerciais. Você pode exportar ou excluir seus dados a qualquer momento.

1. Quem somos

O SnapGestão é um aplicativo de controle financeiro pessoal desenvolvido de forma independente. Para fins desta Política, somos o controlador dos dados pessoais que você nos fornece ao utilizar o aplicativo, conforme definido pela LGPD (Lei 13.709/2018).

Nosso encarregado de proteção de dados (DPO) pode ser contatado em: privacidade@snapgestao.app

2. Dados que coletamos

2.1 Dados de cadastro

  • Email: necessário para criar e identificar sua conta
  • Nome: opcional, utilizado para personalizar a experiência

2.2 Dados financeiros inseridos por você

Todos inseridos voluntariamente, necessários para o funcionamento do aplicativo:

  • Potes (categorias de receitas e despesas)
  • Transações financeiras (valor, data, descrição, categoria)
  • Metas de poupança e reserva de emergência
  • Fontes de receita
  • Lançamentos a confirmar (despesas agendadas)

2.3 Dados de cupons fiscais (NFC-e)

Quando você escaneia um cupom fiscal, processamos temporariamente:

  • Imagem do cupom (processada localmente ou via OCR e descartada)
  • Itens, valores, CNPJ e data do cupom (armazenados como transação)

2.4 Dados de uso técnico

  • Logs de erro para diagnóstico de falhas (sem dados pessoais identificáveis)
  • Versão do aplicativo e sistema operacional (para compatibilidade)

2.5 Dados que NÃO coletamos

O SnapGestão nunca coleta:

  • Dados bancários, senhas bancárias ou de cartões
  • Localização GPS em tempo real
  • Contatos, fotos ou arquivos do dispositivo (além do escaneamento autorizado)
  • Dados de comportamento para publicidade

4. Compartilhamento de dados

4.1 Infraestrutura (suboperadores)

Utilizamos o Supabase (banco de dados e autenticação) como suboperador. Os dados são armazenados em servidores seguros com criptografia em repouso e em trânsito. O Supabase está em conformidade com GDPR e adota práticas equivalentes à LGPD.

4.2 Inteligência Artificial

Ao utilizar o Mentor Financeiro ou o Analisador de Cupons, um resumo dos seus dados financeiros é enviado para provedores de IA (Anthropic Claude, Google Gemini ou Groq). Esses dados são utilizados exclusivamente para gerar a resposta solicitada e não são armazenados ou usados para treinar modelos pelos provedores, conforme suas políticas de privacidade vigentes.

4.3 O que nunca compartilhamos

  • Seus dados com anunciantes ou corretores de dados
  • Informações pessoais identificáveis com terceiros para fins comerciais
  • Dados financeiros detalhados com nenhuma entidade além das listadas acima

5. Base de Preços Colaborativa

Se você optar por participar da base de preços colaborativa, dados anonimizados (nome do produto, preço, estabelecimento, cidade e estado) extraídos dos seus cupons fiscais serão compartilhados de forma agregada com outros usuários do aplicativo.

Importante: Nenhum dado pessoal identificável (nome, email, user_id) é incluído na base de preços. A participação é 100% opcional e pode ser desativada a qualquer momento em Perfil → Dados.

Os dados da base de preços são automaticamente excluídos após 30 dias.

6. Retenção de dados

  • Dados de conta e financeiros: mantidos enquanto sua conta estiver ativa
  • Após exclusão da conta: excluídos em até 30 dias (exceto quando exigido por lei)
  • Base de preços colaborativa: excluídos automaticamente após 30 dias
  • Logs de erro: mantidos por até 90 dias para diagnóstico

7. Seus direitos (LGPD — Art. 18)

Como titular de dados, você tem os seguintes direitos, exercíveis a qualquer momento:

  • Confirmação e acesso: saber se tratamos seus dados e acessá-los
  • Correção: corrigir dados incompletos, inexatos ou desatualizados
  • Anonimização, bloqueio ou eliminação: de dados desnecessários ou excessivos
  • Portabilidade: exportar seus dados em formato estruturado
  • Eliminação: excluir dados tratados com base no seu consentimento
  • Informação: saber com quem compartilhamos seus dados
  • Revogação do consentimento: a qualquer tempo, para finalidades baseadas em consentimento
  • Oposição: ao tratamento realizado com fundamento em legítimo interesse

Para exercer qualquer um desses direitos, entre em contato com nosso DPO em privacidade@snapgestao.app. Responderemos em até 15 dias úteis.

8. Segurança dos dados

Adotamos as seguintes medidas técnicas e organizacionais:

  • Criptografia TLS em todas as comunicações com o servidor
  • Criptografia em repouso no banco de dados (Supabase)
  • Tokens de acesso armazenados de forma segura no dispositivo (SecureStore)
  • Row Level Security (RLS) no banco de dados — cada usuário acessa apenas seus próprios dados
  • Autenticação com confirmação de email obrigatória
  • Chaves de API de IA nunca expostas no cliente

Em caso de incidente de segurança que possa afetar seus dados, você será notificado dentro de 72 horas, conforme exigido pela LGPD.

9. Cookies e armazenamento local

O SnapGestão é um aplicativo móvel e não utiliza cookies de navegador. Utilizamos:

  • SecureStore: para armazenar tokens de autenticação de forma segura no dispositivo
  • SQLite local (expo-sqlite): para cache offline de dados financeiros

Esses dados ficam armazenados exclusivamente no seu dispositivo e são removidos ao desinstalar o aplicativo.

10. Menores de idade

O SnapGestão não é destinado a menores de 18 anos. Não coletamos intencionalmente dados de crianças ou adolescentes. Se identificarmos que um usuário tem menos de 18 anos, sua conta será encerrada e os dados excluídos.

11. Transferência internacional de dados

Seus dados podem ser processados em servidores fora do Brasil (Supabase — AWS us-east-1, provedores de IA nos EUA). Essas transferências ocorrem com salvaguardas adequadas, incluindo cláusulas contratuais padrão e certificações de conformidade equivalentes às exigências da LGPD (Art. 33).

12. Alterações nesta Política

Esta Política pode ser atualizada periodicamente. Alterações relevantes serão comunicadas dentro do aplicativo e exigirão novo aceite quando necessário. A data de vigência no topo deste documento indica a versão atual.

Você sempre pode consultar a versão aceita em Perfil → Legal dentro do aplicativo.

  • Email: privacidade@snapgestao.app

  • Prazo de resposta: até 15 dias úteis
